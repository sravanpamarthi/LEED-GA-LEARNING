# LEED GA Coach

Static study site for a 14-day LEED Green Associate prep sprint.

## What it includes

- 14 daily lessons
- Daily quizzes with saved scores
- Week 1 checkpoint
- Week 2 checkpoint
- 2 final mock exams
- Local progress tracking with `localStorage`

## Files

- `index.html` - app shell
- `styles.css` - visual design
- `data.js` - study plan, lessons, quizzes, checkpoints, mocks
- `app.js` - rendering, grading, and saved progress

## Run locally

Open `index.html` in a browser.

## Publish to GitHub

This project is simple GitHub Pages-friendly static HTML/CSS/JS. You can:

1. Create a new GitHub repo.
2. Push this folder.
3. Enable GitHub Pages for the default branch root.
